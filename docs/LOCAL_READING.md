## Core、Host 与原操作所有权

| Owner | 负责内容 |
| --- | --- |
| Core | 书库与元数据、格式准入/解析、目录与匹配、正文/处理版本、稳定位置、规则和事务原回执 |
| `ReaderLibraryService` 及 Runtime 扩展 | 调用固定 binding，保留原请求/终态、Host 原书和阶段 journal，消费原 ACK 后推进资产清理 |
| `ReaderApplicationModel` | 页面投影、阅读会话身份、位置提交队列、前后台准入及原操作展示 |
| 文件选择与批次 owner | 按选择 operation UUID 汇合系统回调、逐项派发；取消剩余项不伪称在途 Core 写入已取消 |
| 电子书展示层 | 使用 Core 的原条目、章范围和正文版本读取原包；原生 WebKit 展示与选区映射，不另建目录 manifest |
| 网络与资源 Host | 执行 Core 请求、来源会话/凭据隔离、平台取消和图片物理存储，不另建书源或下载业务数据库 |
| 显示/计时 owner | 显示偏好、系统亮度/常亮/方向、自动翻页生命周期，以及有原 UUID 的阅读计时提交 |

书籍、目录、进度、书签、规则和下载任务不另建 Swift 业务库。
Host journal 只保留原操作身份、不可变参数、阶段与原终态，供当前或冷启动 owner 续核。
关闭提示或结果页不结束业务；只读刷新失败不把已确认操作改成失败。

原写入未决时保留原请求与完整参数，不因超时换 ID 重派，也不用 fresh read 冒充原 ACK。
存在 Core exact receipt 时核对原 binding/参数；不存在可靠查询能力时如实保留未决。
下载的冷恢复仅在 Core 对同一原请求明确允许继续时恢复原 job，不能从当前队列推断原写成功。
用户看到的恢复入口投影原 owner，子阶段不能绕过其父操作的剩余步骤。

## 原书、移除与重新处理

Host 以内容身份保留沙箱 `.source` 副本，沙箱路径不充当跨平台书籍身份。
重复内容导入复用既有书籍和进度；一个文件失败不删除其他书或用户下载目录原件。
书架移除先消费 Core 原回执，再按当前资产归属清理可释放的 Host 副本；
旧移除回执不能删除后来重新导入并归新操作所有的同 SHA 资产。
清下载、取消任务、书架移除与删除原书是不同后果，不能互相替代。

规则保存与“重新处理本地书籍”是两步操作。重新处理使用保留原书的同 SHA 与 Core 原解析/
持久化/补偿合同，保持书架元数据、分组和排序；位置迁移由 Core 按内容与版本核验。
歧义或不可迁移时保留既有确认状态，不由 Host 用百分比或旧页码猜测位置。
未知 persist/finalize 仍核对原阶段，不通过再次入架制造成功结果。

真实 TXT 验证输入为下载目录的 `仙子请听我解释.txt`，8,871,723 bytes，
SHA-256 `aac01dbeb5e10710ee802466f077889f5b83d27db70a69e68a33af9ac51658a5`。
历史 V1 原生系统选择器导入得到 948 章，并有切章、滚动、后台/冷启动、控制栏触摸和主题持久化证据；
这些结果只对应其原源码与 App，不证明本轮 V2–V4 已回归完成。
真实书籍不进入仓库，方法级故障注入与真实产品旅程分别记账。

## 阅读位置与生命周期

位置使用书/章身份、Unicode scalar offset、正文版本、处理版本和进度修订。
TextKit 的 UTF-16 下标与 WebKit 的 DOM 下标只用于平台布局，必须映射后才能交给 Core。
原文、解析正文和可见布局不同，不用原始文件字节数或像素位置替代 canonical scalar。
正文重排保留已确认锚点；切章、书签/搜索跳转与重新处理更新 restoration 身份，
旧布局、旧页面和旧请求的回调不能写入新会话。

位置合并后按 Core 原 CAS 修订提交。离页、切章及退后台请求排空原会话；
后台任务只延长系统允许的窗口，不保证任意强制结束前的最后手势已经保存。
重新处理后重新读取 Core 章节、位置和正文，建立新会话，不复用失效版本。

轻量换源由 Core 匹配真实目标章，目标正文成功后以真实正文/scalar/版本/CAS 完成确认。
未知阶段保留原事务；原 rollback ACK 后刷新恢复会话修订，刷新失败只重读。
配套 Core 的原阶段回执方法已通过；iOS 原换源冷恢复及新增 canonical/finalize/rollback 防覆盖场景也已通过定向方法。
下载原 token 在暂停后的处置、继续时新一代 lease 与迟到 Host 请求泵已通过真实 Core/网络方法；
这些结果不替代整个换源/下载界面的原生旅程。

阅读中的前后各两章缓存是有界续读窗口，不等于整本离线下载。
显式下载以 Core 原任务和原 lease 协调 Host 图片落盘；文本已缓存不自动证明插图已离线完成。
新增清下载意图遇到该章未完成的原下载 owner 时先保留未决，不抢先删除其资源；
已派发的原清理仍只核原回执，之后的新读数仅用来保护新一代资产。

## 消息入口登记

组件只展示事实与回传用户意图；写入、恢复、取消和导航仍由业务 owner 决定。

| 业务入口 | 类别与组件 | 身份、失效与清理 |
| --- | --- | --- |
| Bootstrap、书架/目录/工具/书源/下载初载与无内容失败 | 页面状态 `ReaderPageState` | 页面、书/源及请求 generation；新实例不得接收旧结果 |
| 书架筛选、分组与排序投影 | 页面或局部状态 `ReaderPageState` | 完整查询条件与已确认书库快照；不同身份不展示旧子集，同条件刷新保留已确认内容 |
| TXT 当前草稿识别预览 | 局部加载/失败 `ReaderPageState`；诊断与目录为工具正文 | 当前书与原书 SHA、阅读会话、草稿、编辑 ID、全部已保存规则快照及 generation；编辑、换书/会话、离页立即失效，不保存或确认规则写入 |
| 已有内容刷新失败和普通操作反馈 | `ReaderTransientFeedback` 或局部页面状态 | 保留已有内容，由原请求/当前前台宿主控制展示与失效 |
| 在线搜索/换源的来源读取、无结果与筛选空 | `ReaderPageState` | 原来源读取 generation 与当次搜索事实；缺来源、读取失败、停止、部分失败与确认空分开。筛选空只清展示条件，不重新搜索 |
| 已有书源的读回失败 | `ReaderTransientFeedback`，`ReaderOnlineSourceRefreshNotice` 仅作宿主投影 | 原读取失败 UUID，每次最多消费一次；保留已有来源，成功读回清除失败，前台显示两秒，离页/后台取消展示，旧展示不清新代；不确认或重派原写 |
| 本地批次导入的逐项结果 | 专用任务宿主 `ReaderImportResultView` | 原 import/batch UUID；关闭展示不结束原写入 |
| 进度、通用操作、订阅和冷恢复待核对 | 原操作未决 `ReaderRecoveryNotice` 与既有恢复适配 | 原 owner/operation ID；读取成功不清除未知写入 |
| 下载继续与暂停/取消待核对 | 原操作未决的既有 `ReaderOperationStatus` 适配 | 长时继续与短时控制分别持有原 ID；晚结果只结束自身 owner，关闭面板不取消业务，刷新不代替 ACK |
| 规则文件合并导入 | 确认 `ReaderNativeAlertOwner` | 当前规则文件、宿主及 file generation；同 ID 规则/订阅、同名字典以文件内容覆盖，包外项目保留。仅确认后按原 UUID 提交，离页及重读不重发未知写入，导出不写规则 |
| 书源 JSON 草稿替换 | 确认 `ReaderNativeAlertOwner` | 原草稿修订、来稿及页面生命周期；确认前不覆盖，取消/关闭保留，旧文件/链接回调失效。旧草稿与导入文本不推定已保存；可靠 Core 定义或原保存 ACK 才建立已保存基线。保存未决保留同一原 UUID 与输入，冷重开只接回原意图，不自动重派 |
| 移除、规则/书源/订阅等破坏性确认 | `ReaderNativeAlertOwner` | 原实体与意图；确认前不派发，取消确认不改业务 |
| 正文切章、分页和控制栏拖动 | 阅读专用状态与 motion owner | 当前 session、chapter/restoration/gesture generation；旧回调不能解除新状态 |
| 文件选择和来源网页登录 | 登记的原生 Host 适配 | 原选择/来源/请求身份；退出、取消与后续任务交接分别处理 |

新增消息遵守工作区分类入口，不在页面另建同类 Toast、Alert 或消息外框。
书架移除按本地、在线实际合同展示影响；本地目录、正文缓存、进度历史、正文编辑和任务随 Core 移除清理，
原回执确认后才清理 Host 原书副本。书签、笔记、阅读时长及 Downloads 原件保留。
本地章节缓存属于导入解析的物化内容，不因在线下载页面有清理按钮就增加同名删除操作。
TTS 和漫画尚无已开放业务入口，不能把其他阅读入口的证据归给它们。
