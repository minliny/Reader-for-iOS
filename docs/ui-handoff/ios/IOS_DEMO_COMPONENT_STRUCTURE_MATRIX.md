# iOS Demo Component Structure Matrix

Source of truth: `/Users/minliny/Documents/Reader UI/frontend-demo`.

This matrix translates the demo into iOS implementation contracts. It records structure, scope, text hierarchy, dimensions, styles, relative position, and current iOS coverage. It is not a request to copy Web DOM or CSS.

## Scope Rule

- Demo source: `frontend-demo/index.html`, `tokens.css`, `styles.css`, `styles/*.css`, `motion-tokens.css`, `render-runtime.js`.
- Platform target: SwiftUI views under `iOS/App`, `iOS/Features`, `iOS/Navigation`, `iOS/Modules`.
- Translation unit: component contract, not selector. A Web class may map to multiple SwiftUI views.
- Measurement rule: demo px maps to SwiftUI pt 1:1 unless a device API or Dynamic Type requires adaptation.
